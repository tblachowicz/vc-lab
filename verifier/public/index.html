Verifier

Choose which details to ask for. The verifier sends an OpenID4VP request to your wallet, and once you agree, checks the issuer's signature, each disclosure and the wallet's key binding.

DCQL claims

You'll go to the wallet to approve. Claims you don't tick stay in the wallet.

    OpenID4VP 1.0: unsigned request with the redirect_uri: client identifier prefix, a DCQL query, and response mode direct_post. The result is released only to the browser holding the response_code from the wallet's redirect.
